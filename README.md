# Kartensammlung

Web-App (PWA) für Pokémon-Einzelkarten: Suche mit Cardmarket-Preisen, eigene Sammlung mit Wert-Dashboard und Merkliste mit Preisverlauf.

- Daten: [TCGdex API](https://tcgdex.dev) (Cardmarket-Preise, zusammengefasst über alle Sprachen und Zustände)
- Speicherung: lokal im Browser (localStorage)
- Installation auf dem iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“
